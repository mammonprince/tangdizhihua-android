# 棠棣之华 · 安卓非官方增强版

给同样喜欢棠棣的大家：这是一份在原安卓版本上做的游玩体验改进。保留原作剧情、图片和音乐，增加了方便重温、补路线和整理存档的功能。游戏可离线游玩。

## 下载与安装

在本仓库的 **Releases（发行版）** 页面，打开对应版本，在 **Assets（附件）** 下下载 `棠棣之华-魔改版.apk`。下面的 **Source code (zip)** 和 **Source code (tar.gz)** 是 GitHub 自动生成的仓库压缩包，手机安装请选 APK。

将 APK 保存到安卓手机后，点击文件安装。已有同包名、同签名的增强版时，可优先尝试覆盖安装；更新前建议先导出存档。若系统提示签名不一致或无法覆盖，请先保留现有应用和存档。

## 功能与入口

| 功能 | 怎么用 |
| --- | --- |
| 已读高亮 | 在设置中开关。读过的剧情文字会有暖色提示，强制快进跳过的未读文字不会因此被标记为已读。 |
| 两种快进 | 在设置中选择「只快进已读」或「强制快进」，再点「快进」。两种模式都不会代选：遇到剧情选项会暂停，选完后继续；只快进已读遇到未读剧情仍会停下。 |
| 内置 HE 攻略 | 点「攻略」，按路线、章节查看。第八、九章合并显示，长攻略可翻页，关闭后保留阅读位置。 |
| 137 个结局与配图 | 设置 → 结局收集。按状态、路线筛选，或搜索结局名。未解锁时可查看已整理的达成条件；到达结局提示后自动记录，解锁后显示对应的内置配图。筛选条件会保留，已解锁的配图可离线查看。 |
| 存档改名 | 打开「保存进度」或「读取进度」，长按已有档位，再保存新名称。覆盖保存到同一档位后，名称可能恢复为默认章节名。 |
| 剧情回溯 | 在剧情回放里，点击段落旁的转弯箭头并确认，可回到当时的剧情与数值状态。已读与结局收集记录不会被清除。 |
| 剧情长图 | 菜单 → 剧情回放 → 选择分享。勾选段落，生成长图后点「保存图片」，即可存到相册。 |
| 金手指 | 原有金手指移到「设置」，并调整了界面。需要修改数值时，建议先另存一档。 |
| 存档迁移 | 设置 → 导出存档／导入存档。支持用 JSON 备份迁移手动存档、档名、已读记录、结局收集及部分增强设置。 |

结局收集是单独的功能，与原游戏的 CG、音乐收藏分开。结局配图随安装包提供；不需要另外下载图片包。

## 换手机或备份存档

1. 先手动保存当前进度，再从「设置 → 导出存档」保存 JSON 备份。未手动保存的当前剧情不会被自动补存。
2. 把 JSON 传到新手机的本地文件夹。安装游戏后，从「设置 → 导入存档」选择该文件。
3. 核对备份信息和覆盖提示，确认导入，再按提示重新载入游戏，从「读取进度」选择档位。

**导入会用备份替换本机对应的记录，不会合并两边的进度。** 新手机已有想保留的进度时，请先另导出一份。确认能正常读档后，再清理旧手机上的文件。

## 首次权限与已知问题

- 如果设备提示需要文件或存储权限，可按实际提示授予存读档所需权限。游戏画面内的按钮不需要系统悬浮窗权限。
- 回溯只覆盖本次游玩中保留的近期剧情，偶尔有段落不显示箭头，可尝试附近有箭头的段落。重要分歧点建议手动存档。
- 结局列表与达成条件可能涉及剧透。
